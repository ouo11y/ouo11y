# Brand

The ouo11y logo. The mark reads as the letters `ouo` and as a face: two eyes watching, a `u` for the user. All files are hand-drawn SVG with no font dependency. Spelling follows [ADR-0009](../adr/0009-org-and-product-naming.md): always lowercase `ouo11y`.

| File | Content |
|---|---|
| [mark.svg](mark.svg) | app icon / favicon, 64×64 rounded tile; also the Grafana plugin logo |
| [wordmark.svg](wordmark.svg) | `ouo11y` wordmark for light backgrounds |
| [wordmark-dark.svg](wordmark-dark.svg) | wordmark for dark backgrounds |
| [lockup.svg](lockup.svg) | mark + wordmark, light backgrounds |
| [lockup-dark.svg](lockup-dark.svg) | mark + wordmark, dark backgrounds |

Colors: navy `#1f2a44` (tile, `ouo` on light), white (`ouo` on dark, eyes), cyan `#5ac8fa` (`u` in the mark, `11y` on dark), blue `#1a9fd9` (`11y` on light, cyan lacks contrast on white).

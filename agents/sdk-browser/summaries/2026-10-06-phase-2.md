# sdk-browser, 2026-10-06, Phase 2

## Done

`sdk/browser` (`@ouo/browser`, ESM, TypeScript strict, tsup, Vitest + jsdom):

- `src/index.ts` `initRUM()` with the agreed public API (`setUser`, `captureError`,
  `addEvent`, `replay.pause/resume/isRecording`, `session.id/userId`, `flush`), types
  exported from `src/types.ts`.
- `src/session/manager.ts`: session state machine per `docs/specs/session-lifecycle.md`
  (localStorage `ouo.session` / `ouo.user`, 30 min inactivity, 4 h max duration, activity
  throttled persist, same-tab timer, lazy restart after an end, cross-tab `storage` sync,
  `session.previous_id`, replay seq and sampling persisted). Pure, injectable clock and
  storage.
- `src/telemetry/*`: resource (`service.*`, `deployment.environment.name`, `ouo.platform`,
  `ouo.sdk.*`, browser detector, `os.*`), `SessionSpanProcessor` / `SessionLogProcessor`
  (session.id, user.id, ouo.user.anonymous, ouo.platform, service.version on every
  signal), `SessionPropagator` (TraceContext + Baggage with session baggage merged at
  inject time), `EventEmitter` (log records with `event.name`).
- `src/errors/*`: window `error` (capture phase, resource errors too), `unhandledrejection`,
  `console.error`, `captureError`, classified per ADR-0004.
- `src/network.ts`: fetch + XHR instrumentation with `propagateTo`, ignore of OTLP and
  replay URLs, `http.request.failed` for 5xx and network failures.
- `src/vitals.ts`, `src/navigation.ts`, `src/activity.ts`.
- `src/replay/*`: lazy rrweb, chunker (5 s / 256 KB, 2 MB bound, retry), gzip uploader,
  pagehide keepalive, pause/resume, rotation snapshots.
- README with options table, privacy classes, event catalogue. `playground/` throwaway
  page + Node static server + replay stub (`playground/server.mjs`, writes chunks to
  `playground/.chunks`, gitignored).
- kb: `kb/otel-browser-sdk.md`, `kb/rrweb-chunking.md`.

## Not done / caveats

- FCP / LCP / CLS / INP could not be observed: both automation browsers load tabs hidden
  from t=0, so web-vitals discards them by design (TTFB proves the pipeline; the rest is
  unit tested with a mocked web-vitals). Verify in a foreground Chrome window during QA.
- No real browser test of cross-tab sync and of the 30 min / 4 h expiries (unit tested with
  fake timers only).
- Multi-tab replay interleaves seq numbers (documented in kb/rrweb-chunking.md).
- Playground servers were left stopped; `playground/.chunks` is gitignored.

## Contract notes for web-demo and rum-api

- Import: `import { initRUM, type RUM } from "@ouo/browser"` (workspace package; after
  `npm run -w sdk/browser build` the entry is `sdk/browser/dist/index.js`).
- No deviations from the agreed API. Extras: `tracing.ignoreUrls`, `tracing.documentLoad`,
  `replay.flushIntervalMs`, `replay.maxChunkBytes`, `addEvent` attributes get
  `ouo.event.custom=true`, an initial `navigation` event with `ouo.navigation.kind=load`.
- rum-api (Phase 3): accept gzip or plain JSON bodies, CORS preflight for
  `content-type, content-encoding, x-ouo-session-id, x-ouo-seq`, chunk timestamps are
  epoch milliseconds.

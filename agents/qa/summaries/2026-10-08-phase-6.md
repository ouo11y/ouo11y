## Bugs found (not fixed, see `agents/qa/reports/phase-6-bugs.html`)

1. **sdk/browser: duplicate `session.start` on rotation.** Expired session at init -> two
   `session.start` records with different ids at the same ms, same `previous_id`; the second
   is kept, the first is a phantom healthy session in rum-api. Cause: `end()` emits
   `session.end` -> log processor calls `session.id()` -> `ensure()` -> `create()`, then the
   caller calls `create()` again. Reproduced 2/2 (fb2fe879, add731c5). Same pattern likely in
   `ensure()` (timer / lazy restart) and possibly in sdk/react-native.
2. Minor: Tempo search returns trace ids without leading zeros; rum-api / plugin pass them on.
3. Minor: timeline tie-break puts `navigation (load)` before `session.start`.
4. Minor: rum-api `ended_at` is the `session.end` record time, not `ouo.session.ended_at`.

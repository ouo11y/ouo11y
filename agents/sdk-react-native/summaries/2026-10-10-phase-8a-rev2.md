## What changed

### `sdk/react-native` (`@ouo/react-native` 0.2.0, still unreleased, re-cut)

- `src/endpoints.ts` rewritten: `resolveEndpoints({ endpoint, replayEndpoint })` gives
  `${endpoint}/v1/traces`, `${endpoint}/v1/logs`, `replayEndpoint` and
  `${replayEndpoint}/v1/replay/chunks` plus `replayEndpointDerived`; `defaultReplayEndpoint`
  maps an authority port `:4318` to `:4319` (host names, IPv4, bracketed IPv6, path prefixes;
  never a `4318` in the path) and otherwise returns the endpoint itself; `requireCredentials`
  throws a `TypeError` naming `projectId` / `projectToken` (and rejects `:` in the id);
  `base64Encode` (RFC 4648 over UTF-8 bytes, surrogate pairs handled; no `btoa`, no `Buffer`),
  `basicAuthorization(projectId, projectToken)`, `AUTHORIZATION_HEADER`, `DEFAULT_OTLP_PORT`,
  `DEFAULT_REPLAY_PORT`, `REPLAY_CHUNKS_PATH`. Gone: `PROJECT_TOKEN_HEADER`, `INGEST_OTLP_PATH`,
  `requireProjectToken`, `otlpEndpoint` handling.
- `src/types.ts`: `RUMOptions.endpoint` is the collector OTLP/HTTP base, `replayEndpoint?`,
  required `projectId` and `projectToken`; `otlpEndpoint` removed.
- `src/index.ts`: both OTLP exporters get `headers: { Authorization: "Basic …" }`; the replay
  controller gets `endpoints.replayEndpoint`, `projectId`, `projectToken`; ignore patterns are the
  three exact ingest URLs; the debug init line prints `endpoint`, `traces`, `logs`,
  `replayChunks`, `replayEndpointDerived`, `projectId`, truncated token. New exports listed above.
- `src/replay.ts`: `ReplayControllerOptions` and `NativeStartOptions` carry `projectId` and
  `projectToken` (native builds the header itself).
- `playground/scenario.cjs`: `OUO_OTLP` (default `http://localhost:4318`), `OUO_PROJECT_ID`,
  `OUO_PROJECT_TOKEN`, optional `OUO_REPLAY_ENDPOINT`; `OUO_RUM_API` gone.
- `CHANGELOG.md` 0.2.0 (unreleased) rewritten for this contract, with the 0.1.0 migration diff
  and the stock-OTel-SDK note. `README.md` updated (intro, init snippets, endpoints table, replay
  section, API block, playground env, stub test).
- Tests: `test/endpoints.test.ts` (derivation incl. IPv6 and path prefix, explicit
  `replayEndpoint`, base64 vectors against Node's `Buffer`, header value, missing / empty / colon
  ids, `initRUM` installs nothing on a configuration error), `test/ingest-stub.test.ts` (Node stub
  on 127.0.0.1:18082 mimicking `basicauth`: `/v1/traces`, `/v1/logs`, `/v1/replay/chunks`, `401` +
  `WWW-Authenticate` unless `Authorization` equals `Basic ZGVtbzpwdF9kZXZfZGVtb18wMDAwMDAwMDAwMDAwMDAw`,
  asserts no `x-ouo-project-token`), `test/replay.test.ts` (4318 -> 4319 derivation reaches the
  native `start`, proxy host used as is, explicit `replayEndpoint`, exact `NativeStartOptions`
  key set), `test/integration.test.ts` (OTLP routes and the Basic header on every export).

### `sdk/ios` and the Expo module

- `OuoReplayConfig(endpoint:projectId:projectToken:sessionId:...)`: `endpoint` is the replay
  receiver base URL, `projectId:` is new (second parameter), computed `authorization`.
- `ChunkUploader`: `init(endpoint:projectId:projectToken:...)` stores `authorization` once;
  `static basicAuthorization(projectId:projectToken:)` (`"Basic " + Data(...).base64EncodedString()`),
  `static authorizationHeader = "Authorization"`,
  `makeRequest(url:authorization:sessionId:seq:gzipBody:)` sets it on every request, retries
  included. `projectTokenHeader` and the `X-Ouo-Project-Token` header are gone.
  `ReplayRecorder` passes both ids and logs `project=<id>` on start.
- `sdk/react-native/ios/OuoReplayModule.swift`: `StartOptions.projectId` and `projectToken`
  (`@Field`), trimmed; `ERR_OUO_REPLAY_CREDENTIAL` when either is empty (replaces
  `ERR_OUO_REPLAY_TOKEN`).
- Decision recorded in `kb/ios-replay.md`: the bridge carries `projectId` + `projectToken`, not a
  prebuilt header, so native hosts and the bridge share one config shape and the JS and Foundation
  base64 encoders are tested against the same vectors.
- Tests: `PostsGzipJSONWithSpecHeaders` asserts the Basic value and the absence of the old header;
  new `BasicAuthorizationValue` (three vectors incl. non-ASCII, identical to the JS test);
  `EveryRequestCarriesTheBasicCredential` (401 then retries, all three requests carry it,
  `makeRequest` direct check); `RealHTTPAgainstStubWhenConfigured` reads `OUO_PROJECT_ID` too.
- `scripts/sync-ios.mjs` unchanged (copies whatever is in `sdk/ios/Sources`); run by `build` and
  `prepack`, so the vendored pods carry the new initialiser. `sdk/ios/README.md` updated.

## QA: how to verify live on the iOS simulator once the collector is up

1. Stack with `ouo-collector` up: OTLP/HTTP on `:4318`, replay receiver on `:4319`, htpasswd with
   the development project (`demo` / `pt_dev_demo_0000000000000000`), rum-api on loopback `:8080`
   with `OUO_READ_TOKEN`. Sanity from the Mac:
   `curl -s -o /dev/null -w '%{http_code}\n' -u demo:pt_dev_demo_0000000000000000 -X POST -H 'content-type: application/json' -d '{}' localhost:4318/v1/logs`
   must print `200`; without `-u` it must print `401`.
2. The dev client is already installed on the booted "iPhone 18 Pro" with the new native record.
   In `examples/mobile`:
   `EXPO_PUBLIC_OTLP_ENDPOINT=http://localhost:4318 EXPO_PUBLIC_OUO_PROJECT_ID=demo EXPO_PUBLIC_OUO_PROJECT_TOKEN=pt_dev_demo_0000000000000000 BACKEND_URL=http://localhost:8081 EXPO_PUBLIC_QUIET_LOGBOX=1 npx expo start`
   (ports as in your `deploy/docker/.env`; on this Mac the backend has been on 8082), then open
   the app on the simulator (`xcrun simctl launch booted dev.ouo.mobilestore` or tap it). If the
   native module ever looks stale: `npm run -w sdk/react-native build && npx expo run:ios --no-bundler --device "iPhone 18 Pro"`.
3. Metro log must show `[ouo] @ouo/react-native@0.2.0 initialised {endpoint: "http://localhost:4318",
   traces: ".../v1/traces", logs: ".../v1/logs", replayChunks: "http://localhost:4319/v1/replay/chunks",
   replayEndpointDerived: true, projectId: "demo", projectToken: "pt_dev_d…"}` and `[ouo] replay:
   started {endpoint: "http://localhost:4319", ...}`, and no `[ouo:otel] export response failure
   (status: 401)`. Native: `xcrun simctl spawn booted log show --last 2m --predicate 'process == "mobilestore"' | grep "ouo replay"`
   shows `started endpoint=http://localhost:4319 project=demo ...`, `queued ... seq=0`, `uploaded seq=0`.
4. Drive Products -> Product -> Add to cart -> Cart -> Checkout; wait ~7 s. Then with the read
   token: `curl -s -H "Authorization: Bearer $OUO_READ_TOKEN" 'localhost:8080/v1/sessions?from=now-1h&platform=mobile' | jq '.sessions[] | {session_id, status, replay_kind, replay_frame_count}'`
   must list the session with `replay_kind: "frames"`; `GET /v1/sessions/<id>` timeline must show
   `navigation` events; Tempo must have the `HTTP GET/POST` client spans joined with the backend;
   every resource must carry `ouo.project.id = "demo"` (stamped by the collector, not by the SDK).
5. Negative checks: restart Metro with `EXPO_PUBLIC_OUO_PROJECT_TOKEN=pt_wrong` -> Metro shows
   `export response failure (status: 401)` and the native log shows `upload of seq=0 failed
   (httpStatus(401))`; `otelcol_receiver_refused_*` / the basicauth rejections rise on the
   collector. Then `curl -s -X POST localhost:8080/v1/replay/chunks` from a phone on the LAN must
   fail (rum-api on loopback only), while `http://<mac-lan-ip>:4318` and `:4319` must answer.
6. Optional: `OUO_REPLAY_STUB_URL=http://localhost:4319 OUO_PROJECT_ID=demo OUO_PROJECT_TOKEN=pt_dev_demo_0000000000000000 ./test.sh --filter RealHTTP`
   in `sdk/ios` pushes two real gzip chunks through URLSession with the Basic header; and
   `cd sdk/react-native && SCENARIO=healthy OUO_OTLP=http://localhost:4318 node --require ./playground/preload.cjs playground/scenario.cjs`
   runs the headless flow against the collector.

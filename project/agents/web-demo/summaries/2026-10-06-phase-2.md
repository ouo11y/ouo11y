# web-demo, 2026-10-06, Phase 2

## Built

`examples/web` ("web-store"): Vite 7 + React 18 + TypeScript strict + react-router 6, no UI library.

- Pages: `/` product grid (`GET /api/products`), `/products/:id` (qty + add to cart), `/cart`
  (backend cart, +/- and remove via `POST /api/cart`), `/checkout` (name, email, card number
  `.ouo-mask`, toggleable promo field `.ouo-block`, payment method `card` / `broken-card`,
  `POST /api/checkout`), `/order/:id`, `/chaos`, 404.
- Header "User" control: input + button -> `localStorage["ouo.demo.user_id"]`, `rum.setUser({id})`,
  `x-user-id` on every API call. Footer shows `rum.session.id()` and `rum.session.userId()`
  (polled every 2 s) and the app version.
- `src/rum.ts`: the only module that imports `@ouo/browser`. Reads `VITE_OTLP_ENDPOINT`,
  `VITE_RUM_API`, `VITE_BACKEND_URL`, `VITE_APP_VERSION`, `VITE_RUM_DEBUG` with the defaults from
  `deploy/compose/.env` on this machine (4328 / 8082). `tracing.propagateTo` is derived from the
  backend URL. `.env.example` committed.
- `src/rum-stub.ts` + `VITE_RUM_STUB=1`: Vite alias and `tsconfig.stub.json` map `@ouo/browser` to a
  console-logging implementation of the same interface (`npm run build:stub`, footer shows
  "(rum stub)"). Not used by the default `build`.
- `src/api.ts`: fetch wrapper (`ApiError` with status, fault flags `delay` / `fail`, `x-user-id`),
  no manual `traceparent` / `baggage`.
- Events: `add_to_cart {product_id, qty}` on add to cart, `checkout_submitted
  {payment_method, item_count, total}` on checkout submit.
- Chaos panel (`/chaos` page and floating "chaos" drawer on every other page): slow
  (`?delay=2000`), 500 (`POST /api/checkout?fail=500`), timeout (`?fail=timeout`, AbortController
  5 s), uncaught throw in click handler, unhandled rejection, `rum.captureError(new Error("handled"))`,
  `console.error("console failure")`, `rum.addEvent("add_to_cart", ...)`, replay pause/resume showing
  `isRecording()`, `rum.flush()`. Each action logs its outcome and duration in the panel.
- `README.md`: run, env vars, demo script (healthy / errored / crashed), Grafana Explore queries,
  curl version of the flow.
- `project/kb-archive/web-demo-storefront.md` (backend JSON quirks, stub approach, React dev double-report).

response's `items` is a count, not an array.

## Dependencies added (examples/web)

- `react`, `react-dom` 18: required by the MVP (ADR-0005).
- `react-router-dom` 6: client routing for the five pages; v6 is the stable line for React 18.
- `@ouo/browser` 0.1.0 (workspace link): the SDK under test.
- dev: `vite` 7, `@vitejs/plugin-react` 5, `typescript` 5, `@types/react`, `@types/react-dom`:
  build toolchain required by ADR-0005. Nothing else (no UI library, no state library).

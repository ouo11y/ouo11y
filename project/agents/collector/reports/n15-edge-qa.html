How it ran

deploy/scripts/qa-edge.sh n13-collector-qa --out-dir project/agents/collector/reports/n15-runs runs tests/e2e/edge-qa.mjs twice: profile default on the env as built from this branch, then it recreates the collector with OUO_RATELIMIT_CLIENT_KEY=x_forwarded_for and small buckets (project 1/s burst 40, client 1/s burst 10), runs profile limits, and restores the stock collector on exit. Requests go to the env's published collector ports (OTLP http://localhost:20100), the proxy leg of xff through the env's Traefik host. Mimir is read for the self-metrics (pushed every 15 s), Tempo for the spans, rum-api with the read token.

Not covered: the background check runs the React Native SDK's code under Vitest with the unit tests' react-native stand-ins (the AppState transition is simulated; ingest, Loki and rum-api are real). The iPhone and the simulators were in use by the benchmark session. "Quota" in N15 is the per-project token bucket: per-project quotas beyond it are a later phase (ADR-0007).

Findings

IdWhatObserved
V1Viewer can DELETE a replay through the plugin proxy (route `rum/*`, method `*`, reqRole Viewer)DELETE -> 204

V1: the plugin's only route, rum/*, has method: "*" and reqRole: Viewer, so any Viewer can call rum-api's DELETE /v1/sessions/{id}/replay with the read token Grafana injects. The plugin UI has no delete button, but the proxy accepts the call. Fix (grafana-plugin, plugins/ouo11y-rum-app/src/plugin.json): a GET route for Viewer and a DELETE route for Editor or Admin. The check records it as a finding until then.

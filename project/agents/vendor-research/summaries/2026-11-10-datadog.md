## What the next agent must know

- **Browser v7 replay is not rrweb.**
  - Full snapshots are `type 2, format 1` change lists, and DOM mutations and inputs are `type 12` Change records.
  - There is a string table with roles, and node ids are implicit.
  - Use `examples/datadog-capture/decode-change-snapshot.mjs` to read one.
- **Mobile replay is wireframes**: full snapshot type 10, incremental type 11. Default masking happens on the device.
- With `proxy` set, the browser does not send `view_update` unless `betaEnableViewUpdates: true`. Mobile always sends it. Any receiver must merge `view_update` by `view.id` and `_dd.document_version`.
- The browser trace id is 64-bit (upper half of `traceparent` is zero).
- Sampling uses the Knuth factor on the last UUID group of the session id, on all SDKs.
- **npm quirk on this Mac:** `npm` fails with "Exit prior to config file resolving" when run from inside the worktree. Run it from a neutral directory with `npm install --prefix <dir>`.
- The iOS 27 SDK requires the UIScene life cycle. Apps without a SceneDelegate fail to launch.
- Correction to Step 4 TRN-c: v7.17.0 does not use `fetch` keepalive. Normal sends are plain `fetch`, and page exit uses `sendBeacon` on all browsers.

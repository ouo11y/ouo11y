PASS Build, tests, typecheck, lint

npm run -w plugins/ouo-rum-app build compiles (webpack 5, dist/ with module.js, chunks, plugin.json, logo). test: 2 jest suites, 14 tests (percentage/duration/relative-time formatting, marker positioning, seek clamping, latest-event index, replay bounds). typecheck clean. lint 0 errors (3 deprecation warnings for Select).

PASS Plugin loaded unsigned and provisioned

Compose bind-mounts plugins/ouo-rum-app/dist at /var/lib/grafana/plugins/ouo-rum-app; a missing dist directory is created empty by Docker Desktop so Grafana still starts. Grafana 13.2.1 logs Permitting unsigned plugin and Plugin registered. GET /api/plugins/ouo-rum-app/settings returns enabled: true, pinned: true, jsonData.rumApiUrl: http://rum-api:8080 (from deploy/compose/grafana/provisioning/plugins/ouo-rum-app.yaml).

PASS Route proxy to rum-api

GET /api/plugin-proxy/ouo-rum-app/rum/v1/stats/health?from=now-7d returns rum-api's JSON through the rum/* route. With empty jsonData the template falls back to http://rum-api:8080 (/rum/healthz still ok); with a wrong port Grafana answers 502. /api/plugins/<id>/resources/... is the backend-plugin endpoint and returns 500 for this frontend-only app (documented in kb).

TypeScript + React 19 + `@grafana/{data,ui,runtime}` 13.2.2, npm workspace):

- Scaffolded with `@grafana/create-plugin` 7.12.1 (frontend parts only; the generator ignored
  `--backend=false` and hung, see kb). Build toolchain untouched (`.config/` webpack + swc,
  jest + swc, eslint 9). Root `tsconfig.json` adds the hoisted `@types` path.
- `src/plugin.json`: `includes` Overview (`defaultNav`), Sessions, Session detail

- `src/api`: typed client for every rum-api endpoint through
  `/api/plugin-proxy/ouo-rum-app/rum/v1/...` (`getBackendSrv().fetch`), errors carry the
  proxied URL and a hint when Grafana answers 502.
- **Overview**: `TimeRangePicker` with `from`/`to` in the URL; per platform (web, mobile)
  three stat tiles (healthy / errored / crashed %, counts) computed from the rum-api buckets
  with rum-api's rounding, and a version table (total, healthy, errored, crashed, stacked
  bar) whose rows link to Sessions pre-filtered (platform, service, version, range).
- **Sessions**: filters platform, status, service, version, user, limit (all in the URL),
  time range picker; table with started, status badge, platform, service/version, user, id,
  duration or "active", errors, crashes, failed requests, traces (`n/a` when -1), replay
  icon; row click / Enter opens the detail with the range.
- **Session detail**: header (id, status, state + end reason, user, platform, service,
  started, ended or last signal, duration, counts); Timeline panel (relative `+12.3s`, icon and
  colour per type, fatal red / handled orange, web vital name value rating, custom attrs;
  click seeks the replay; the latest event at or before the replay cursor is highlighted and
  scrolled into view); Replay panel (`rrweb-player` 2.1.7, `autoPlay: false`,
  `showController`, `skipInactive`, width fitted with ResizeObserver, marker bar with ticks for
  fatal / error / failed request / navigation positioned by `(ts - start) / duration`, click
  = `player.goto(ms)`, cursor and `+time` label driven by `ui-update-current-time`); Traces
  panel (root name, service, start, duration, spans, error badge, trace id + copy, "Open in
  Explore" using `grafana_url` in a new tab).
- Error states (`Alert` with message + proxied URL + retry) and empty states (`EmptyState`).
- Config page (`/plugins/ouo-rum-app`): `rumApiUrl`, saved via `POST /api/plugins/<id>/settings`.
- `deploy/compose/compose.yaml`: plugin volume uncommented;
  `deploy/compose/grafana/provisioning/plugins/ouo-rum-app.yaml` enables the app with
  `jsonData.rumApiUrl=http://rum-api:8080`; `deploy/README.md` plugin section.
- Tests (jest, 14): `src/utils/format.test.ts` (percentages, durations, relative times,

## Not done / caveats

- `InteractiveTable` was not used (no row click); tables are styled `<table>` elements.
- Replay seeks use `player.goto(ms)` without changing play state; rrweb-player's own progress
  bar and our marker bar are separate (the marker bar sits under the player).
- The Browser pane opened the `target="_blank"` Explore link in the same tab; in a normal
  browser it opens a new tab.
- `Select` from `@grafana/ui` is deprecated (lint warnings); `Combobox` can replace it later.
- Trace counts are read from rum-api as-is (Tempo indexing lag applies, see project/kb-archive/tempo-session-search.md).
- No e2e (Playwright) tests; the scaffold's e2e setup was dropped.

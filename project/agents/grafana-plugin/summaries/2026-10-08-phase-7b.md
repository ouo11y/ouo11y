## What was done

1. **Session detail keeps the replay in view** (`src/pages/SessionDetail.tsx`, `src/components/Timeline.tsx`,
   `src/components/FramePlayer.tsx`, `src/utils/scroll.ts`)
   - Replay panel: `position: sticky; top: 8px; align-self: start` inside the two-column grid.
   - Timeline panel: flex column stretched to the row; the event list is the only scroll container
     (`flex: 1; max-height: calc(100vh - 150px); overflow-y: auto; overscroll-behavior: contain`).
   - Frame stage cap changed from `70vh` to `calc(100vh - 300px)` so the whole Replay panel (header,
     scrubber, markers, info) fits the viewport. Before, a portrait frames replay made the panel 851px
     tall in a 900px window, so it was the tallest row item and sticky had no room to act; the user
     saw the frame scroll off while reaching the controls.
   - Active event auto-scroll now adjusts only the list's `scrollTop` (`scrollRowIntoView`, nearest
     semantics, one `requestAnimationFrame` per index change) instead of `element.scrollIntoView`,
     which would also scroll the page and move the pinned replay.
   - Below 900px (`@media (max-width: 899px)`) the panels stack, Replay first, no sticky.
   - Traces panel untouched.
2. **Replay column** (`src/components/SessionsTable.tsx`, `src/utils/format.ts` `replaySummary`,
   `src/api/types.ts`): `replay_duration_ms` / `replay_frame_count` added to `SessionRecord`;
   the cell shows the duration formatted like the Duration column plus a small kind badge
   (`rrweb` with the `brackets-curly` icon, `frames` with `camera`), the old play icon while the
   duration is unknown (older rum-api), and "–" without a replay. rum-api started returning
   `replay_duration_ms` during this run, so the real durations were verified in the browser.
3. **Sortable columns** (`src/utils/sort.ts`, `SessionsTable.tsx`): every header is a button with
   `aria-sort`, an arrow on the active column and a tooltip saying the sort is client-side over the
   loaded page; default Started desc; numeric columns start desc, text columns asc, status sorts by
   severity (healthy < errored < crashed), replay by none < unknown < length; ties fall back to newest
   start then session id. `InteractiveTable` was not used (kb: no row click handler). The Sessions
   page subtitle mentions the client-side sort.
4. `formatDuration` rounding fix: 299.6s rendered "4m 60s" on the marker bar, now "5m 00s".

## What was done

- `sdk/react-native` (`@ouo/react-native` 0.1.0, TypeScript strict, tsup CJS bundle with the
  OTel packages inlined): `initRUM`, `RUMProvider`, `navigationStateListener`, session manager
  (AsyncStorage, 30 min inactivity, 4 h max, 30 s background, cold-start `crash` / `terminated`
  end for the persisted session, `session.previous_id`), AppState bridge, `ErrorUtils` global
  handler with `ouo.exception.fatal = isFatal` + crash marker + bounded flush, unhandled
  rejections (Hermes tracker / window), `console.error` and `captureError` as handled
  non-fatal, `fetch` wrapper with CLIENT spans, `traceparent` + `baggage` for `propagateTo`,
  `http.request.failed` on 5xx / network failure, resource with `service.version`, `os.*`,
  `device.*`, `ouo.sdk.version`; every span and log carries `session.id`, `user.id`,
  `ouo.platform=mobile`, `service.version`.
- Fixes this run: (1) test leak (post-uninstall `ErrorEvent` reported by vitest), (2)
  **Expo web bug**: Expo bundles `ErrorUtils` for web, so the SDK skipped the window listeners
  and a fatal thrown from `setTimeout` was never captured; window `error` /
  `unhandledrejection` listeners are now installed alongside `ErrorUtils`, de-duplicated per
  error object (new test), (3) `navigationStateListener` no longer blanks
  `ouo.navigation.from`, (4) test file typechecks without the DOM lib.
- `examples/mobile`: Expo 57 managed app "mobile-store" (own package.json + lockfile, not a
  workspace; SDK via `file:` + `metro.config.js`), screens Products / Product / Cart /
  Checkout (`card` / `broken-card`) / Order / Chaos (slow, 500, handled, unhandled rejection,
  fatal from `setTimeout`, console.error, custom event, set user, flush), header badge
  `v<version> · <session>`; `app.config.ts` `extra` with the local ports, `version` 2.3.0
  overridable by `APP_VERSION`. README added.
- `project/kb/otel-react-native.md` filled (shims, bundling, Metro linking, session and error rules,
  gotchas). `project/tracker/mvp.md` Phase 5 boxes ticked except the simulator one.

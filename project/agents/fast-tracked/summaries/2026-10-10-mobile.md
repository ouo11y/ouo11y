# 2026-10-10 fast-tracked: Expo iOS onboarding guide

## What was done

A Markdown guide for an engineer adding `@ouo/react-native` plus native screenshot replay to
their own Expo app on macOS 27 / Xcode 27, iOS only. Sections: what you get; Mac setup (Xcode
27 from the App Store, Components > iOS 27, `xcode-select` or `DEVELOPER_DIR`, CocoaPods with
the `LANG=en_US.UTF-8` quirk, Node 24, stack ports); consuming the unpublished SDK through the
npm `file:` link, `npm run -w sdk/react-native build` (sync-ios + tsup), per-package
`npx expo install` lines with reasons, the Metro config, the Expo module bridge (three podspecs,
`expo-module.config.json`, autolinking); four ref files inlined in full (`metro.config.js`,
`app.config.ts`, `plugins/withUIScene.js` with the iOS 27 UIScene explanation, `src/rum.ts`);
instrumentation with the "we do this ourselves" callout, every `initRUM` and `replay` option
as a table, `ouo-mask` / `ouo-unmask`, automatic versus manual; prebuild / pod install /
simulator / `expo run:ios --device "iPhone 18 Pro"` / log reading; a text diagram of the
telemetry path with the env variables and verification curls (rum-api, Loki, Tempo, Grafana);
a reading-order code walk (app, RN SDK, Expo bridge, Swift package); an appendix on running
on a physical iPhone (signing with a personal team, Developer Mode, trust, LAN IP via
`ipconfig getifaddr en0`, Metro `--lan`, firewall, ATS, Local Network prompt, USB note); a
gotcha list.

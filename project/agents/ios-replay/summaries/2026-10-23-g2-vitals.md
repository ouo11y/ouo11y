## Done

- `sdk/ios`: new targets `OuoVitalsCore` (C: process start from `sysctl` `kp_proc.p_starttime`,
  image load time from a constructor before `main`) and `OuoVitals` (Swift: `AppStartInfo.resolve`
  for cold / prewarmed cold / warm, `FrameCounter` with sentry-cocoa's slow rule (`1/(fps-1)`,
  frozen >= 700 ms, delay = sum of overruns), `CADisplayLink` tracker on the main run loop with a
  weak proxy and a reset on resign/become active, `os_unfair_lock`). Product `OuoVitals`.
- `sdk/react-native/ios`: pods `OuoVitalsCore` / `OuoVitals` (vendored by `scripts/sync-ios.mjs`,
  gitignored copies), `OuoReactNative` depends on `OuoVitals`. Expo module: `OnCreate` starts frame
  tracking; `getAppStartInfo()` (once per module instance, `{processStartMs, type, prewarmed}`) and
  `getFrameStats()` (`{total, slow, frozen, delayMs, expectedFrameMs}`), the contract of #44.
- JS: only the `NativeVitalsModule` type (`prewarmed`) and comments; README, CHANGELOGs, sdk/ios README.
- Tests: `OuoVitalsTests` (14 Swift tests: frame classification at 60/120 Hz, jitter tolerance,
  delay, reset, bad timestamps, cold/warm/prewarm resolution, kernel process start vs now and the
  image load, second runtime warm, per-frame cost bound). `sdk/ios/test.sh`: 47 + 6 tests pass.
  `npm test`/`typecheck` in `sdk/react-native` pass.

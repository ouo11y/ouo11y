# 2026-10-08 Phase 7: iOS replay capture (sdk/ios) and the Expo module

Agent: ios-replay. Branch `phase-7-ios-replay`, files left uncommitted for the orchestrator.
Scope per ADR-0006 and `docs/specs/mobile-replay.md`. rum-api (`kind: frames`) and the
Grafana frame player were built concurrently by other agents.

## What was done

- **`sdk/ios`** Swift package `OuoReplay` (tools 5.9, iOS 15 / macOS 13), two targets:
  - `OuoReplayCore` (Foundation + zlib): `FrameChunk`/`Frame`/`Touch`/`Viewport` with the
    spec's snake_case keys; `ChunkBuilder` (flush at 5 s, 10 frames, explicit; seq and session
    id reserved when the chunk opens; `sessionDidRotate` flushes and resets seq to 0);
    `SeqStore` protocol with `InMemorySeqStore` and `UserDefaultsSeqStore` (persists
    `{session_id, seq}`, a new id restarts at 0); `FrameDeduper` (injectable hasher, FNV-1a);
    `RedactionPlanner` over a `ViewNode` tree (masked class list incl. RN text/image views,
    superclass matching, `ouo-mask` / `ouo-unmask`, hidden/alpha/offscreen skipping, window
    clipping, overlap merge); `Gzip` (zlib `deflateInit2` with gzip wrapper, verified with
    `/usr/bin/gunzip`); `ChunkUploader` (`ChunkTransport` protocol, URLSession transport,
    spec headers, in-order sends, 3 attempts with 1 s / 2 s backoff, 2 MB bounded queue).
  - `OuoReplay` (UIKit, `#if canImport(UIKit)`, macOS stub prints "iOS only"):
    `OuoReplayConfig`, `OuoReplay.start/pause/resume/isRecording/flush/sessionDidRotate/stop`,
    `ScreenCapturer` (key window `drawHierarchy`, black fills from the planner, render scale
    chosen so the longest side is <= 1000 px, JPEG 0.5, 16x16 grayscale thumbnail for dedupe),
    `ViewTreeBuilder`, `TouchObserver` (observing `UIGestureRecognizer`, no interference,
    moved samples coalesced to 50 ms, cancelled reported as `ended` per rum-api), `ReplayRecorder`
    (1 Hz main run-loop timer in `.common` mode, touch captures <= 4/s, background flush,
    foreground resume frame, host pause survives backgrounding).
  - Tests: `Tests/OuoReplayCoreTests` (Swift Testing, 35 tests + 1 env-gated real-HTTP test),
    fixture `Fixtures/chunk.json` from the spec. `test.sh` wraps `swift test` with the framework
    paths the Command Line Tools need. README.
- **`sdk/react-native`** became an Expo module: `expo-module.config.json`
  (`apple.modules: OuoReplayModule`, `swiftModuleName: OuoReactNative`, Android class),
  `ios/OuoReplayModule.swift` (ExpoModulesCore `Module`: `start(endpoint, options: Record)`,
  `pause`, `resume`, `isRecording`, async `flush`, `sessionDidRotate`, `setSessionId`, `stop`),
  three podspecs (`OuoReplayCore`, `OuoReplay`, `OuoReactNative`) so the package's Swift modules
  survive CocoaPods, `scripts/sync-ios.mjs` vendoring `sdk/ios/Sources` into `ios/` on
  `npm run build` (gitignored copies), `android/` no-op `OuoReplayModule.kt` that logs once.
  JS: `src/replay.ts` (`loadNativeReplayModule` via guarded `require("expo-modules-core")`,
  `defaultReplayEndpoint` = OTLP host on 8080, `createReplayController` no-op when disabled or
  native absent), `initRUM({ replayEndpoint, replay })`, `rum.replay.pause/resume/isRecording`,
  `SessionManager.onRotate` -> `sessionDidRotate`, `rum.flush()` awaits the native flush,
  `_uninstall` stops it. Types updated. Tests `test/replay.test.ts` (17) with
  `test/mocks/expo-modules-core.ts`. `expo-modules-core` optional peer dependency; `files`
  now ship `ios`, `android`, the config. README section.
- **`examples/mobile`**: `replay: { enabled: true }`, promo-code `TextInput` with
  `testID="ouo-mask"` on Checkout, `testID="ouo-unmask"` on the Product title, Chaos button
  "Replay pause/resume (recording|off)", `expo-modules-core` added to the Metro PEERS redirect
  (otherwise the SDK's require cannot resolve), README dev-client section. `npx expo prebuild
  --platform ios --no-install` generated `ios/` (gitignored) and switched the `ios`/`android`
  npm scripts to `expo run:*` (kept).
- Docs: `project/kb/ios-replay.md`, `project/kb/xcode-setup.md`, `project/kb/index.md`, `project/tracker/mvp.md` Phase 7
  boxes 1, 2, 3 and 7 ticked (box 6, simulator verification, stays open).

## Verification

1. `cd sdk/ios && swift build`: Core and the macOS stub compile (CLT, Swift 6.3).
2. `cd sdk/ios && ./test.sh`: 35 tests in 7 suites pass (chunk JSON key set equals the spec
   fixture, flush triggers, seq monotonic/persisted/reset incl. UserDefaults across instances,
   dedupe A-B-A, planner: masked classes, subclasses, flags, `ouo-mask`, `ouo-unmask`, hidden,
   alpha, clipping, merge; gzip magic/ISIZE/round trip/large input/`gunzip -c` exit 0; uploader
   headers + gzip body decode, order + retry delays [1, 2], give-up after 3, bounded queue drops
   the oldest, head never dropped).
3. `OUO_REPLAY_STUB_URL=http://localhost:8080 ./test.sh --filter RealHTTP`: two gzip chunks
   through `URLSession` to the live rum-api; `GET /v1/sessions/swift-uploader-1791472085/replay`
   -> `kind: frames, chunk_count 2, first_seq 0, last_seq 1, frame_count 5, bytes 469`;
   `/replay/frames` returns the 5 frames in seq order with the exact base64 payloads.
4. `npm run -w sdk/react-native build` (sync + tsup) and `npm run -w sdk/react-native test`:
   7 files, 56 tests pass; `tsc --noEmit` clean.
5. `examples/mobile`: `tsc --noEmit` clean; `expo-modules-autolinking resolve -p apple` lists
   pods `OuoReactNative`, `OuoReplay`, `OuoReplayCore` with module `OuoReplayModule` and Swift
   module `OuoReactNative`; `-p android` lists `sdk/react-native/android`; `npx expo export
   --platform ios` builds the Hermes bundle with the replay code.
6. **Not verified (needs Xcode)**: compiling the UIKit target and the Expo module, `pod
   install`, `expo run:ios`, masked fields black in Grafana, pause stopping chunks. Xcode did
   not appear during the run (`/Applications` has only Xcodes.app; `xcrun --sdk iphonesimulator`
   fails). `brew install cocoapods` was started and was still building Ruby/CocoaPods at the end
   of the run; `pod install` needs Xcode's `xcodebuild` anyway.

## What is left / what the next agent must know

- Follow `project/kb/xcode-setup.md`, then expect a first compile pass of
  `sdk/ios/Sources/OuoReplay/*.swift` and `sdk/react-native/ios/OuoReplayModule.swift` (written
  blind; likely spots: ExpoModulesCore `Record` syntax for the installed version, `UIScreen.main`
  deprecation warning, `Exception` initializer signature).
- The chunk's `viewport.scale` is the render scale (pixels per point, e.g. 1.17 for an iPhone
  15 at 1000 px cap), not the spec example's 0.5; the player multiplies touch points by it.
- `sdk/react-native/ios/OuoReplayCore` and `ios/OuoReplay` are generated copies; edit `sdk/ios`.
- Dependencies added: none at runtime. `expo-modules-core` is an optional peer (the Expo
  module API); no new devDependencies (the mock replaces it in Vitest). Root
  `package-lock.json` updated for the peer entry.
- Interfaces consumed from rum-api: `POST /v1/replay/chunks` ack body and limits (8 MiB, 1000
  frames) are far above what the SDK produces (10 frames per chunk, ~20-40 KB each).

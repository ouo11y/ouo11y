Per frame the main thread does one Objective-C message from the display link, two timestamp reads, an uncontended os_unfair_lock and a few double operations. getAppStartInfo runs once per JS runtime and getFrameStats once per window, on the JS thread. Not verified here

  • Prewarmed launches (image-load start): iOS does not prewarm on the simulator; covered by AppStartTests.
  • A physical device and a Release build of the app (the iPhone was taken by the benchmark session).
  • Screen windows after taps: the run had no taps, so only the app_start window has app.jank; per-screen windows use the same counters.

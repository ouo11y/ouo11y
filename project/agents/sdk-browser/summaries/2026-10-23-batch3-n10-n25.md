# 2026-10-23 batch 3: browser SDK gaps (N10, N25, 8b browser sampling)

Owner: sdk-browser (`sdk/browser`, `examples/ouo-web`). Env: `ouo-env up b3-browser-sdk` (checkout build, admin / testing567).

## Done

- **Web Vitals in a real browser (why they were never seen):** (1) automation panes load tabs hidden, so web-vitals drops FCP/LCP/CLS/INP (known); (2) what is emitted at page hide was lost: the OTel batch processors skip a flush while one is running and wait for the in-flight export's response, and Chromium fires `pagehide` (our flush) before `visibilitychange` (CLS, INP); (3) web-vitals 6.2.3's forced final INP runs before its pending interaction entries are processed. Fixes: `src/telemetry/batch.ts` (own batcher, flush exports at once), INP with `reportAllChanges` emitted from the SDK's hide handlers (`visibilitychange` and `pagehide`, Safari). Also the journey closed the browser before keepalive requests left (harness artefact, fixed).
- **Interaction tracing:** `src/interactions/` — `FallbackContextManager`, `InteractionTracker` (idle `click` / `soft-navigation` spans, also a SpanProcessor counting children), click instrumentation. Childless clicks are not exported. Log records are emitted in the root context.
- **Soft navigations:** `soft-navigation` span per route change under the causing click; `rum.setRoute` / `app.screen.name`.
- **Long tasks:** `ouo.long_animation_frame` (Chromium 123+, longest script attributed) or `ouo.long_task`.
- **Rage and dead clicks:** `ouo.rage_click`, `ouo.dead_click` with `app.widget.*` / `app.screen.coordinate.*`.
- **React:** `@ouo11y/browser/react` subpath (`OuoErrorBoundary`, `useOuoRoute`, `routeTemplate`), React optional peer, SDK imported by package name (shares the instance). Console duplicate of a boundary error suppressed.
- **Meta traceparent:** documented in the SDK README (Go / Node snippets); e2e test and a run against the env (documentLoad parent = the meta span id in Tempo). No `examples/backend` change (bridge-owned).
- **Multi-tab replay:** one recording tab per session via a BroadcastChannel lease, `ouo.tab` rrweb custom events.
- **Sampling (8b):** `session.sampleRate` (Sampler + log filter, sampled flag 00 propagated), `replay.onErrorSampleRate` (30-60 s in-memory buffer, uploaded on the first error, persisted `replayTriggered`). Decisions use the rule agreed with the 8b session (rum-api cap, React Native): `fmix32(fnv1a32(salt + ":" + id)) / 2^32 < rate`, salts `session` / `replay` / `replay_on_error`, its test vectors in `test/sampling.test.ts`.
- **Bundle budget:** `size-budget.json`, `npm run size:check` in the CI `node` job. 42.8 KB gzip (was 40.1; the own batcher removed the OTel batch processors).
- **Cross-browser CI:** `examples` job, web leg: SDK Playwright suite (`e2e/`, 9 tests x 3 engines) then `run.sh --browsers chromium,firefox,webkit --playwright-image <pinned>`, both in the Playwright image (the first CI run timed out in `playwright install --with-deps` on a stalled apt mirror). Also fixed a race in `test/ingest-stub-server.test.ts` (waited for the replay chunk only; on a fast runner the fetch span had not ended yet).
- 0.x OTel packages pinned exactly (N26).

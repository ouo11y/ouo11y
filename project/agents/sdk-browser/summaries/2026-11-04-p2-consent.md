# 2026-11-04 P2 consent (client JUHI, web roadmap WB7 part)

## Done

- `@ouo11y/browser`: `initRUM({ consent: "pending" | "granted" })` (default `"granted"`), `rum.setConsent({ telemetry, replay })`, `rum.getConsent()`, `CONSENT_QUEUE_LIMIT` (100). `src/consent.ts` gates `install()` (the old `initRUM` body): pending installs nothing; calls (`setUser`, `clearUser`, `captureError`, `addEvent`, `setRoute`) queue, drop-oldest; grant installs and runs the queue; replay consent pauses the recorder before `start()` (rrweb never imported); revoke halts delivery (`Delivery.halt()`), shuts down, removes `ouo.device` / `ouo.session` / `ouo.user`, deletes IndexedDB `ouo-delivery`; a grant after a revoke waits for the wipe. No change to `src/replay/recorder.ts` (PR #152).

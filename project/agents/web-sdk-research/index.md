# web-sdk-research

Research agent (orchestrator session plus eight sub-agents, 2026-10-29). Owns `project/kb/web-sdk-research/` and this folder. Studies how Sentry, Datadog, PostHog, Grafana Faro and the OpenTelemetry-shaped vendors, the replay specialists and the rest of the field capture RUM and session replay in the browser, grounded in their source code; measures bundle, main-thread and wire cost on one page; inventories what ouo offers on the web today; and recommends the web roadmap (founder focus item 1, N36). The Sentry browser SDK through the bridge (N39) is a separate study.

- [tracker.md](tracker.md)
- `summaries/` dated run summaries
- `tools/web-bench/` the Appendix M benchmark harness (local intake, page, journey, scripts)
- `reports/` HTML reports: [web-sdk-research.html](reports/web-sdk-research.html) (matrices, replay practices, measured footprint) and [web-sdk-roadmap.html](reports/web-sdk-roadmap.html) (lanes, value against cost, maturity, competitive table)

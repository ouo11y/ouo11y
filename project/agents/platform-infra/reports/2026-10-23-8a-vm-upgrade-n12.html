6. Findings

bug rum-api cannot write its bind-mounted data dir on Linux fixed

Root-owned deploy/data/rum-api, image runs as 65532. install.sh chowns it before up. Hidden by Docker Desktop on a Mac. Affects every Linux compose install, 0.2.0 included.

bug Grafana image upgrades keep the first plugin (images mode) fixed

grafana-data over /var/lib/grafana hides the image's plugin; 0.2.0 → 0.3.0 crash-loops. New grafana-plugin one-shot service in deploy/compose/compose.images.yaml (also fixes ouo-env up --images upgrades on laptops). The 0.3.0 tag does not have it: upgrade to main or the next release.

bug ouo.service ignores the install mode fixed

Hard-coded build files: systemctl start after an images install rebuilt from source and swapped Grafana. ExecStart/ExecStop are now written per mode; the unit is started, not only enabled.

bug 0.2.0 installer cannot upgrade to 0.3.0 migrated

ADR-0010 moved deploy/docker to deploy/compose. The new installer moves .env and projects.htpasswd, hands over only to installers that know the protocol (env var guard; old scripts reject unknown flags). One-time step documented in upgrade.md.

bug Sentry bridge unreachable on the VM fixed

4320 neither published nor routed. Caddy /api/* → 4320, loopback publish, DSN key generated for new installs and printed. Remaining gap: bridged data is stamped ouo.project.id=demo (collector config, not this PR).

minor re-run without --ref moved the install to main; CORS doc pointed at the collector config; no docker-buildx fixed

Re-runs keep the checked-out commit; --allowed-origins writes OUO_ALLOWED_ORIGINS; docker-buildx in the apt list.

observation trip points documented, not code

sudo docker login (root pulls), sudo git (dubious ownership), private repo needs a read token for clone and --ref fetches, CURL_CA_BUNDLE / NODE_EXTRA_CA_CERTS for tls internal, e2e.sh needs OUO_GRAFANA_URL = public URL, Helm 4 --rollback-on-failure, --reuse-values keeps old tags, bare self-signed leaf does not verify, helm lint passes HA values that helm template refuses without Secrets, otlp-headers with existingProjectsSecret.

observation for other owners

The 0.2.0 e2e has_error lookup does not normalise Tempo's stripped leading zero (trace 04e66... came back as 31 chars; the data had has_error: true). The chart has no Sentry bridge. Compose-built rum-api reports dev. Listed as checklist N23.

environment tooling

kind loading multi-arch images from Docker Desktop's containerd store needs docker save --platform | ctr import. Self-hosted Sentry started mid-run (17.2 of 19.5 GiB) and starved the kind API server and Grafana's probes; release A was torn down before the external-mode check. A registry credential was not moved into the VM; images went in with docker load.

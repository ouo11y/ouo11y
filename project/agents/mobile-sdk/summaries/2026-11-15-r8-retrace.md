# 2026-11-15 R8 / ProGuard retrace (ADR-0027)

## Done

- ADR-0027 (proposed): a random mapping id per minified build, sent as `ouo.exception.mapping_id`; CI uploads `mapping.txt` to Muninn kind `proguard`; retrace on read. Muninn spec 13 and mobile-sdk spec C2 updated.
- `sdk/android/gradle/ouo-mapping.gradle`: AGP variant API script; every minified variant gets the asset `ouo-debug-meta.properties` and `build/outputs/ouo/<variant>/mapping-id.txt`. `sync-android.mjs` copies it to `sdk/react-native/android/vendor/`.
- `signals-core` `Report.mapping_id` and `Report.mappingId(text)`; `Signals` reads the asset at `init` and sets the id on crash, hang and termination reports. JVM unit test.
- `sdk/android/sample`: minified app that applies the script and crashes through code R8 inlines. CI job `android` builds it and checks the APK's id equals `mapping-id.txt`.
- React Native `crash.ts`: `ouo.exception.mapping_id` when the report has one and frames are sent.
- `ouo-sourcemaps upload-proguard <mapping.txt> --id|--id-file`; tests for the function and the CLI.
- `libs/ouo-go/symbolicate/proguard.go`: R8 format 2.x parser and retrace (ranges, single-line, unranged, inline groups, cross-class inlining, synthetic rows dropped, exception class), `ResolveJVM`, `FromEvent` reads JVM frames and the mapping id. Muninn already accepted kind `proguard` (ADR-0026).

# 2026-10-29 ADR-0014 and ADR-0016

## What was done

- [ADR-0014](../../../../docs/adr/0014-replay-tiles-in-frames.md), tiles in `frames` schema 2. A frame carries either a full JPEG (`jpeg`, the same field as schema 1, so a schema 1 frame is a valid schema 2 full frame) or `patches` (`x, y, w, h, jpeg`) against the last frame *sent*. A full image is forced when the last one is ≥ 6 s old, on a screen change, on resume, and at the start of a session or buffer flush; a static screen sends nothing. Three modes go in a new `mode` field: `session`, `buffer` (30 s on-disk ring, uploaded on the first error or crash) and `navigation`. Also covered: the player's seek and `seq`-gap rules, how a schema 1 reader behaves, the upgrade order, and the W3 exit target (≤ 150 KiB/min at T3 masked).
- [ADR-0016](../../../../docs/adr/0016-opentelemetry-in-process.md), OpenTelemetry in process. Android builds on opentelemetry-android with a pinned version and ouo's own session provider. iOS stays dependency-free, with its own OTLP/JSON exporter. opentelemetry-swift-core is the documented opt-in fallback.
- `docs/adr/README.md` has two rows (0015 is left to the W2 session). `docs/specs/mobile-replay.md` has a one-paragraph pointer: schema 1 stays normative until W3.
- This agent folder was created.

## Decisions taken while writing (not in the roadmap's words)

- The full image keeps the field name `jpeg` rather than `image`, and patches use `jpeg` too. The format stays named in the field, as in schema 1. The benefit: the frames endpoint passes frames through and a session may mix schema 1 and 2 chunks, so rum-api needs no conversion.
- The 6 s keyframe rule applies to the next frame *sent*. A periodic keyframe on a static screen would break W3's "a static screen sends zero image bytes".
- A viewport change ends the chunk, because `viewport` is per chunk.
- When patches would cover more than half the frame, the SDK sends a full image instead.

## How it was verified

- The schema 1 reader behaviour was read from the code. `services/rum-api/internal/replay/parse.go` and `collector/receiver/ouoreplayreceiver/chunk.go` reject `schema_version > 1` as invalid (400). `schema.go` holds the start-up guard. `stream.go` passes frame JSON through unchanged. `plugins/ouo11y-rum-app/src/utils/frames.ts` assumes a `jpeg` on every frame.
- `lychee --offline` over the whole repo (the AGENTS.md command): 953 links, 0 errors.
- No code changed, so there are no tests to run. The `links` CI job is the check that applies.

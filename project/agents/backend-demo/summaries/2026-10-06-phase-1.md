# backend-demo: Phase 1 run (2026-10-06)

## What was built

`examples/backend` (Go module `github.com/ZiadMansourM/ouo/examples/backend`,
Go 1.26, standard library `net/http` + `otelhttp`):

- `main.go`: server on `:8081` (`PORT` override), graceful shutdown that
  flushes telemetry, `-check` flag used as the distroless container HEALTHCHECK.
- `internal/telemetry`: OTLP/HTTP exporters for traces, logs and metrics
  (standard `OTEL_EXPORTER_OTLP_*` env), resource `service.name` (env, default
  `demo-backend`), `service.version=0.1.0`, `deployment.environment.name=local`;
  composite W3C TraceContext + Baggage propagator; `BaggageSpanProcessor` that
  copies `session.id`, `user.id`, `ouo.platform` from baggage onto every span;
  `slog` default logger fans out to stdout and the `otelslog` bridge.
- `internal/api`: CORS (reflects `http://localhost:*` / `http://127.0.0.1:*`
  plus `CORS_ALLOWED_ORIGINS`, preflight 204, allow-headers include
  `traceparent`, `tracestate`, `baggage`), in-memory product catalogue and
  per-user carts, handlers `GET /healthz`, `GET /api/products`,
  `GET /api/products/{id}`, `GET|POST /api/cart`, `POST /api/checkout` with
  child spans `inventory.lookup`, `cart.load`, `payment.charge`, `db.query`;
  fault injection `?delay=<ms>` (sleep inside `db.query` span with
  `db.system.name=postgresql`, `db.query.text`), `?fail=500` (RecordError,
  status Error, error log), `?fail=timeout` (30 s hang, cancels on client
  disconnect); `paymentMethod=broken-card` deterministic 500. One `request` info
  log per request with `session.id`/`user.id`/`ouo.platform` from baggage.
  `/healthz` is excluded from tracing and request logs (HEALTHCHECK noise).
- Metrics: otelhttp `http.server.request.duration` plus `ouo.demo.requests`,
  `ouo.demo.orders`, `ouo.demo.checkout.duration`.
- `Dockerfile` (multi-stage `golang:1.26` -> `distroless/static:nonroot`, CGO
  off, 28.6 MB image), `.dockerignore`, `README.md`.
- Tests: `internal/telemetry/baggage_test.go` (baggage `session.id=abc` ->
  server span attribute `session.id=abc`, also on child spans; unrelated
  members not copied; `traceparent` joins the incoming trace),
  `internal/api/api_test.go` (every endpoint, cart identity precedence, checkout
  OK and broken-card error status/exception event, fault flags, timeout cancel,
  CORS allow/deny and env origins, route-pattern span names, no spans for
  `/healthz`).

## What the orchestrator must know

- This dev machine already has unrelated stacks on 4317/4318, 3200, 3100 and
  3000. The ouo compose stack therefore runs on 4328 (OTLP/HTTP), 3201 (Tempo),
  3101 (Loki), 3001 (Grafana) through `deploy/compose/.env`. The commands in the
  task brief (`localhost:3200`, `localhost:3100`, `4318`) hit the wrong stack
  here; the compose-internal endpoints (`otel-collector:4318`) are unaffected.
- The compose file passes `CORS_ALLOWED_ORIGINS`; the backend honours it as an
  extra exact-origin allow list on top of the localhost wildcard.
- Tempo search needs explicit `start`/`end`; see `project/kb-archive/otel-go-baggage.md`.
- Counter metrics appear in Mimir without `_total` (OTLP-native naming).
- `?fail=timeout` hangs 30 s; the server `WriteTimeout` is 45 s so the hang is
  real. A client that disconnects earlier frees the handler immediately.

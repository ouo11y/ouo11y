# rum-api, Phase 8a: ingest gateway and project tokens (2026-10-10)

Branch `phase-8a-install-secure`. Scope: implement ADR-0007 in `services/rum-api`: OTLP
ingest routes behind a public project token, per-project CORS and limits, authenticated
replay uploads, a read token for the plugin side, ingest metrics.

## What was done

New packages:

- `internal/project` (`project.go`, `project_test.go`): `Project`, `Registry`, `Load(Source)`.
  Reads `OUO_PROJECTS_FILE` (YAML of the ADR, `KnownFields` strict) or the env fallback
  (`OUO_PROJECT_ID` default `default`, `OUO_PROJECT_TOKEN` required, `OUO_ALLOWED_ORIGINS`).
  Startup fails with `no project configured: set OUO_PROJECTS_FILE or OUO_PROJECT_TOKEN`
  when neither is set; duplicate ids / tokens, empty tokens, negative limits and bad origin
  patterns are also startup errors. `Lookup(token)`, `AnyAllowsOrigin(origin)` (preflights),
  `Project.AllowsOrigin`. Origin patterns `scheme://host[:port]`: `*` replaces exactly the
  leading host label or the port, otherwise exact; case-insensitive scheme/host, trailing
  slash tolerated, default ports 80/443 folded, IPv6 literals supported, `null` never matches.
- `internal/ingest`:
  - `limiter.go`: token bucket `Limiter` (rate, burst, injected clock, idle buckets swept
    inline from `Allow` once per minute, no goroutine, `0` disables) and `ProjectLimiter`
    (one `Limiter` per project; project `rate_limit` overrides the defaults).
  - `otlp.go`: decode (protobuf or OTLP/JSON with `DiscardUnknown`), `stamp` (sets
    `ouo.project.id` on every resource, creates missing resources, removes a client-sent
    copy), deterministic protobuf encode, `normalizeOTLPJSON` (hex ids to base64, numbers
    kept verbatim via `json.Number`).
  - `gateway.go`: `Gateway` with `Handler(signal)` for the three OTLP routes, `Authorize`
    for the replay route, `RecordAccepted` / `RecordRejected`, forward to
    `OUO_COLLECTOR_OTLP_ENDPOINT/v1/<signal>` with `OUO_COLLECTOR_TIMEOUT`, collector
    status / `Retry-After` / body passed back (transcoded to JSON for JSON clients), 502 on
    transport error or timeout, client IP from the peer or the last `X-Forwarded-For` hop
    with `OUO_TRUST_PROXY=true`. Four OTel counters created from the global meter provider
    (overridable in tests).

Changed:

- `internal/httpapi/server.go`: routes `POST /ingest/otlp/v1/{traces,logs,metrics}`,
  `Options.Gateway` (required, `New` panics without it: there is no auth-off mode),
  `Options.ReadToken`; handler chain `cors(readAuth(mux))`; `bearerMatches` is a constant-time
  compare.
- `internal/httpapi/cors.go`: per-project CORS (`Registry.AnyAllowsOrigin` plus deprecated
  exact `CORS_ALLOWED_ORIGINS`), the ADR header list, `Access-Control-Expose-Headers:
  Retry-After, X-Ouo-Replay-Kind`, `Vary: Origin`, 403 for a preflight from a disallowed
  origin, the implicit localhost reflection removed; `readAuth` for `GET`/`DELETE`/`HEAD
  /v1/*` with `WWW-Authenticate: Bearer`.
- `internal/httpapi/replay.go`: `Gateway.Authorize` (Content-Length vs the frames limit,
  token, Origin, rate) before the body is read; `project_id` passed to the store; every
  reject counted (`size` / `decode`), `ErrWrongProject` -> 403; accepted chunks counted with
  their decompressed bytes.
- `internal/replay/store.go`, `fs.go`: `Store.Put(ctx, projectID, body, gzipBody)`,
  `Meta.ProjectID` (`project_id`, `omitempty`), `ErrWrongProject` (session owned by another
  project, nothing written), legacy `meta.json` without `project_id` reads fine and adopts
  the first project that writes to it. On-disk layout otherwise unchanged.
- `internal/config/config.go`, `main.go`: the new variables, `project.Load` and `ingest.New`
  before the server (startup error messages `projects: ...` / `ingest gateway: ...`); the
  forward client uses the otelhttp transport like Loki / Tempo; startup log shows the
  collector, project count and whether a read token is set.
- `README.md`: architecture, run command, env table, projects file format, auth / CORS
  section, ingest section with the check order and codes, metrics, `project_id` in replay
  meta, curl examples (OTLP/JSON trace with token, read token on every read call),
  deprecated `CORS_ALLOWED_ORIGINS` note, layout.

### Routes and codes

- `POST /ingest/otlp/v1/traces|logs|metrics`: 413 size, 401 token, 403 origin, 429 rate
  (`Retry-After`), 400 decode, then the collector's status (200 `{"partialSuccess":{}}` for
  JSON clients), 502 collector unreachable.
- `POST /v1/replay/chunks`: 413 / 401 / 403 / 429 as above, then the existing 400 / 409 /
  413 chunk rules; 403 when the session's replay belongs to another project.
- `GET` / `DELETE /v1/*`: 401 without `Authorization: Bearer <OUO_READ_TOKEN>` when set.
- `OPTIONS` preflight: 204 with CORS headers when any project allows the origin, 403 otherwise.

### Dependencies

- `gopkg.in/yaml.v3 v3.0.1` (new): the projects file is YAML per the ADR; yaml.v3 is the
  standard Go YAML decoder with no runtime dependencies and strict `KnownFields`
  (`sigs.k8s.io/yaml` would pull a go-yaml fork plus json round-tripping for nothing).
  `github.com/kr/text` appears in go.mod as `// indirect` because `go mod tidy` records
  yaml.v3's test dependency graph; it is not compiled in.
- `go.opentelemetry.io/proto/otlp v1.11.0`, `google.golang.org/protobuf v1.36.12`,
  `go.opentelemetry.io/otel/metric v1.47.0`, `google.golang.org/genproto/googleapis/rpc`
  (all already indirect, now direct): OTLP request types, proto / protojson codecs, the
  counters, and `google.rpc.Status` for transcoding collector error bodies.
- Rate limiter written in the package (no `x/time/rate`).

## What is left

  Postgres registry behind `project.Registry`.

  setting it.

## What the other agents must know

- **platform-infra**: rum-api now needs `OUO_PROJECT_TOKEN` (or `OUO_PROJECTS_FILE`) or it
  exits with `projects: no project configured ...`. Compose dev values: `OUO_PROJECT_ID=demo`,
  `OUO_PROJECT_TOKEN=pt_dev_demo_0000000000000000`,
  `OUO_ALLOWED_ORIGINS=http://localhost:*,http://127.0.0.1:*`,
  `OUO_READ_TOKEN=rt_dev_0000000000000000`, `OUO_COLLECTOR_OTLP_ENDPOINT=http://otel-collector:4318`
  (default). Drop `CORS_ALLOWED_ORIGINS` and the collector CORS block; SDKs and the e2e /
  smoke scripts post to `rum-api/ingest/otlp/v1/<signal>` with the token header. Health and
  readiness probes are unchanged (`/healthz`, `/readyz`, `rum-api -check`).
- **helm**: same variables; `OUO_PROJECTS_FILE` points at a mounted ConfigMap / Secret for
  multi-project installs; set `OUO_TRUST_PROXY=true` only behind an ingress that overwrites
  `X-Forwarded-For`. Only rum-api (and Grafana) are exposed; the collector stays ClusterIP.
- **plugin**: every `GET` / `DELETE /v1/*` needs `Authorization: Bearer <readToken>` from
  `secureJsonData.readToken` through the route proxy; a missing token is 401 with
  `WWW-Authenticate: Bearer`. Replay meta now carries `project_id`. Browser origins of the
  Grafana UI do not need to be in any project when calls go through the proxy.
- **sdk / web / mobile**: `X-Ouo-Project-Token` on `/ingest/otlp/v1/{traces,logs}` and
  `/v1/replay/chunks`; OTLP/JSON with hex ids is fine; 429 carries `Retry-After` (exposed
  to the browser); a disallowed origin is 403 at the gateway and the preflight is 403 too.
- **qa**: `ouo.ingest.requests{reason}` tells which check rejected a request; the live
  sequence above is reproducible with the README curl examples.

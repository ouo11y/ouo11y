# mobile-sdk-research

Research agent (orchestrator session plus eight Opus sub sessions, 2026-10-29). Owns `project/kb/mobile-sdk-research/` and this folder. Studies how Sentry, PostHog, Luciq and the other mobile RUM / replay vendors capture RUM and session replay on native iOS (Swift, Objective-C), native Android (Kotlin, Java), React Native and Flutter, grounded in their source code; records wire size, performance claims and measurement methods, OTel export and the feature matrix, and derives recommendations for ouo's native SDKs.

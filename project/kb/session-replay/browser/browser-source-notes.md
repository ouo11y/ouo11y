## 1. rrweb record (upstream 2.2.2)

### 1.1 Entry point and options
1. `record(options)` destructures every option with its default: `blockClass='rr-block'`, `ignoreClass='rr-ignore'`, `maskTextClass='rr-mask'`, `recordCanvas=false`, `recordAfter='load'`, `collectFonts=false`, `inlineImages=false`, `sampling={}`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L66-L103
2. Input masking defaults: `maskAllInputs:true` turns on all 16 input kinds; otherwise `maskInputOptions` if given; otherwise only `{password:true}`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L140-L162
3. One module-level `Mirror` is reused and `mirror.reset()` runs on each `record()` call, so node ids restart per recording. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L65 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L137-L138
4. `init()` = `takeFullSnapshot()` then `observe(document)`. It runs at once if `readyState` is `interactive`/`complete`; otherwise it waits for `DOMContentLoaded` or `load` (default), and emits `DomContentLoaded` (type 0) / `Load` (type 1) events on the way. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L588-L618
5. The returned stop function runs every observer handler, then tears down the iframe, shadow-DOM and canvas managers. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L619-L646

### 1.2 Event envelope, plugins and checkouts
6. `wrappedEmit` stamps `timestamp = nowTimestamp()`, runs plugin `eventProcessor`s and the optional `packFn`, then calls the user `emit(event, isCheckout)`. From a cross-origin child frame it `postMessage`s `{type:'rrweb', event}` to the parent instead. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L171-L218
7. Any event that is not a FullSnapshot or Mutation first unfreezes frozen mutation buffers and the canvas manager. `record.freezePage()` pauses DOM recording until the next user event. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L189-L206 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L673-L676
8. **Checkouts**: each IncrementalSnapshot increments a counter. When `checkoutEveryNth` is reached, or `timestamp - lastFullSnapshot.timestamp > checkoutEveryNms`, it calls `takeFullSnapshot(true)`. Neither option has a default. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L220-L241
9. Each observer callback is wrapped into `{type: IncrementalSnapshot (3), data:{source: IncrementalSource.X, ...}}`. Plugins emit `{type: Plugin (6), data:{plugin, payload}}`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L431-L564
10. Custom events and the new annotations: `record.addCustomEvent(tag, payload)` emits type 5, and `record.addAnnotation()` emits type 8 (`Annotation`, new in 2.x). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L653-L671
11. Enums: `EventType` 0..8 = DomContentLoaded, Load, FullSnapshot, IncrementalSnapshot, Meta, Custom, Plugin, Asset, Annotation. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/types/src/index.ts#L1-L11. `IncrementalSource` 0..16 = Mutation, MouseMove, MouseInteraction, Scroll, ViewportResize, Input, TouchMove, MediaInteraction, StyleSheetRule, CanvasMutation, Font, Log, Drag, StyleDeclaration, Selection, AdoptedStyleSheet, CustomElement. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/types/src/index.ts#L145-L163

### 1.3 Full snapshot, node ids, Mirror
12. `takeFullSnapshot` emits Meta (type 4: `href,width,height`), resets the stylesheet manager, and **locks** the canvas manager and every MutationBuffer so the mirror cannot change mid-snapshot. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L344-L366
13. It calls rrweb-snapshot `snapshot(document, …)` with hooks that register iframes, `<link>` stylesheets and shadow roots as they are serialized. It then emits FullSnapshot (type 2, `{node, initialOffset}`) and **unlocks** the buffers; unlocking flushes the mutations queued during the snapshot. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L367-L426
14. Ids: a module counter `_id` starts at 1 and `genId()` returns `_id++`. `IGNORED_NODE = -2` marks nodes dropped by slimDOM, which are still put in the mirror so `nextSibling` lookups work. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L36-L43
15. `serializeNodeWithId` decides masking once per subtree (`needMaskingText` checks ancestors only when the parent's answer is unknown). It reuses the id if the node is already in the mirror, otherwise it calls `genId()`. Then `mirror.add(n, serialized)`, and it recurses into children and shadow-root children. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L924-L1129
16. `Mirror` = `Map<id, Node>` + `WeakMap<Node, serializedNode>`. `getId` returns -1 for unknown nodes, and `removeNodeFromMap` recursively drops a subtree from the id map. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/utils.ts#L192-L262
17. Text masking: masked text keeps its length because every non-whitespace character is replaced with `*` (or `maskTextFn` runs). `<script>` text becomes `SCRIPT_PLACEHOLDER`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L498-L539 ; the selector/class check is in https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L266-L307
18. Input values go through `maskInputValue`, which masks if the tag or `type` is enabled in `maskInputOptions` and writes `'*'.repeat(len)`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L617-L639 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/utils.ts#L267-L296
19. Blocked elements (`blockClass`/`blockSelector`) are kept as an empty element with only `class`, `rr_width` and `rr_height` taken from `getBoundingClientRect()`, and their children are skipped. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L759-L767 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L1048-L1052
20. With `recordCanvas`, a 2D canvas that is not blank, or a canvas with an unknown context that differs from a blank canvas of the same size, gets `rr_dataURL = toDataURL()` in the snapshot. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/snapshot.ts#L659-L690

### 1.4 MutationBuffer: batching per MutationObserver callback
21. One `MutationObserver` per document or shadow root, watching `attributes`, `attributeOldValue`, `characterData`, `characterDataOldValue`, `childList` and `subtree`. Its callback is `processMutations`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L82-L110
22. `processMutations` = run `processMutation` on each record (accumulate), then `emit()` once. So **one MutationObserver callback produces at most one Mutation event**, unless the buffer is frozen or locked. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L129-L154
23. `characterData` → push `{node, value}` (masked) into `texts` if the value changed and the node is not blocked. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L463-L486
24. `attributes` → masks `value`, skips the update if unchanged or blocked, and merges into one `attributeCursor` per node (`attributeMap`). Style changes are tracked as a per-property `styleDiff`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L487-L602
25. `childList` → `genAdds` for added nodes and `removes.push({parentId,id})` for removed serialized nodes. Nodes added and then removed in the same batch are dropped (`droppedSet`). A node removed and re-added under the same parent is treated as a move (`movedSet` + `movedMap`). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L603-L674 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L679-L715
26. `emit()` returns early when frozen or locked, then applies pending mirror removals. It walks `addedSet` so that each node is serialized after its parent (parentId requirement) and its next sibling (nextId requirement), with `serializeNodeWithId(..., skipChild:true, newlyAddedElement:true)`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L156-L356
27. The payload is `{texts, attributes, removes, adds}`. Text and attribute changes on nodes that were just added are dropped because the add already carries the current value. A style diff replaces the full `style` string only when it is shorter. An all-empty payload is not emitted. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/mutation.ts#L359-L429

### 1.5 Other observers (defaults)
28. **Mouse move**: positions are sampled at most every `sampling.mousemove` = **50 ms** (`trailing:false`) and buffered with a `timeOffset`. They are emitted as one event per `mousemoveCallback` = **500 ms** with source MouseMove (1), TouchMove (6) or Drag (12). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L112-L196
29. **Mouse interaction**: one listener per `MouseInteractions` key (`mouseup/down` become `pointerup/down` when PointerEvent exists) emits `{type,id,x,y,pointerType?}`. Individual kinds can be turned off through `sampling.mouseInteraction`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L198-L315
30. **Scroll**: throttled at `sampling.scroll || 100` ms; the document scroll is reported as `getWindowScroll`, elements as `scrollLeft/Top`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L317-L358
31. **Viewport resize**: throttled at **200 ms** and only emitted when width or height changed. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L360-L384
32. **Input**: listens to `input`+`change` (only `change` if `sampling.input==='last'`). It skips blocked or ignored targets, masks via `maskInputOptions`, dedups per element (`lastInputValueMap`), and also emits the implied uncheck of sibling radios. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L388-L487
33. Programmatic value changes are caught by patching the `value`/`checked`/`selectedIndex`/`selected` setters on the Input/Select/TextArea/Option prototypes; these are reported with `isTrusted:false`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L497-L534
34. **Media**: `play/pause/seeked/volumechange/ratechange` throttled at `sampling.media || 500` ms emit `{type,id,currentTime,volume,muted,playbackRate,loop}`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L1024-L1067
35. **StyleSheetRule**: `CSSStyleSheet.prototype.insertRule`/`deleteRule` (and the grouping-rule variants) are wrapped in a `Proxy`, so CSS-in-JS rule injection that never touches the DOM is still recorded. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L598-L650
36. **Fonts** (`collectFonts`): replaces `window.FontFace` and patches `document.fonts.add`; binary font sources are serialized as a JSON array of bytes. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L1069-L1128
37. **Selection**: on `selectionchange`, emits each range as `{start,startOffset,end,endOffset}` node ids, skipping blocked ranges. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L1130-L1169
38. **Custom elements**: patches `customElements.define` and emits `{define:{name}}`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L1171-L1207
39. `initObservers` wires all of the above; the stylesheet, declaration and font observers run only with `recordDOM`, and plugin observers come last. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observer.ts#L1305-L1375

### 1.6 Canvas
40. `CanvasManager` picks one of two modes: `sampling.canvas === 'all'` (the default) records draw **commands**; a number records **FPS snapshots**. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observers/canvas/canvas-manager.ts#L69-L86
41. Command mode: the 2D context prototype methods are patched and their arguments serialized (`serializeArgs`). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observers/canvas/2d.ts#L31-L55. WebGL1/2 prototypes are patched as well (https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observers/canvas/webgl.ts#L90-L127). Commands are queued per canvas and flushed once per `requestAnimationFrame` as one CanvasMutation (9) event `{id,type,commands}`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observers/canvas/canvas-manager.ts#L287-L314
42. FPS mode: every `1000/fps` ms, the rAF loop calls `createImageBitmap(canvas)` and posts the bitmap to an inline worker. The worker encodes it with `OffscreenCanvas.convertToBlob` and skips frames that are unchanged or fully transparent. The reply is turned into a synthetic `clearRect` + `drawImage(ImageBitmap(Blob(base64)))` command pair. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/observers/canvas/canvas-manager.ts#L120-L232 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/workers/image-bitmap-data-url-worker.ts#L66-L82

### 1.7 Visibility / page hide
43. rrweb record has **no** `visibilitychange` handling. The only `pagehide` listener is in the iframe manager, which stops observing an unloading same-origin iframe document. Flushing on hide is left to the embedding SDK (see §3, §4, §5). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/iframe-manager.ts#L134 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/record/index.ts#L579-L586

## 2. rrweb replay

44. `new Replayer(events, config)` needs at least 2 events (unless `liveMode`). Defaults: `speed 1`, `maxSpeed 360`, `skipInactive false`, `inactivePeriodThreshold 10 s`, `useVirtualDom true`, `UNSAFE_replayCanvas false`, `pauseAnimation true`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L182-L215
45. `setupDom` builds `.replayer-wrapper`, the fake mouse cursor, a mouse-tail canvas and the iframe. By default the iframe comes from `createSandboxedIframe`; only `UNSAFE_replayCanvas` uses `sandbox="allow-same-origin allow-scripts"`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L602-L640
46. **Sandbox (new hardening)**: `createSandboxedIframe` ignores any caller `sandbox` attribute, forces exactly `sandbox="allow-same-origin"` (no scripts), and records the document in a WeakSet. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/rebuild.ts#L777-L805. `rebuild()` throws unless the target is such a document or `UNSAFE_allowUnprotectedRebuild` is set. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/rebuild.ts#L157-L191. Recorded `<script>` elements are rebuilt as `<noscript>`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/rebuild.ts#L18-L19
47. Events are unpacked (`unpackFn`), sorted by timestamp and fed to an xstate player machine with a `Timer`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L344-L368
48. **Play at offset**: `discardPriorSnapshots` keeps only events from the last Meta before the target time. Events before `baselineTime` go to `syncEvents` and are applied at once (`applyEventsSynchronously`); later events become timer actions with `delay`. Then `Flush` is emitted and the timer starts. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/machine.ts#L66-L79 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/machine.ts#L171-L218
49. **Timer**: one rAF loop advances `timeOffset += elapsed * speed` and runs every action whose `delay <= timeOffset`. Late events are inserted by binary search (live mode). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/timer.ts#L28-L79. A mouse-move event's delay is taken from its first position (`timestamp + positions[0].timeOffset`). https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/timer.ts#L119-L137
50. **Speed / skip inactive**: when the next user-interaction event is more than `inactivePeriodThreshold × speed` away, the player fast-forwards at `min(round(gap / 5 s), maxSpeed)` and emits `skip-start`. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L95 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L719-L758
51. `getCastFn` dispatches by type: Meta → resize, FullSnapshot → `rebuildFullSnapshot` + `scrollTo(initialOffset)`, Incremental → `applyIncremental`, Custom/Annotation → emitter. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L672-L803
52. `rebuildFullSnapshot` resets the mirror and calls rrweb-snapshot `rebuild(node, {doc: iframe.contentDocument, afterAppend, cache, mirror})`, then attaches queued iframe documents and inserts the replay CSS rules. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L805-L883 ; `rebuild` itself is https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb-snapshot/src/rebuild.ts#L735-L764
53. **applyMutation**: during a sync (seek) pass, the first mutation builds an RRDom virtual document from the live iframe DOM (`buildFromDom`), and all further sync mutations go to the virtual tree. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L1407-L1431
54. Order inside one mutation event: removes first (warning about ids missing from the mirror) → adds via `appendNode`, which uses `parentId`/`nextId`/`previousId`. Adds whose parent or next sibling is not there yet go to `legacy_queue`, which is resolved as trees within a 500 ms budget. Then texts, then attributes. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L1433-L1490 , https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L1509-L1520 , https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L1718-L1780
55. **Fast-forward flush**: on `Flush`, if the virtual DOM was used, `diff(iframe.contentDocument, virtualDom, replayerHandler)` patches the real DOM once and replays canvas, input, scroll and stylesheet side effects through the handler. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrweb/src/replay/index.ts#L224-L272 ; the diff is a two-ended keyed children diff (`diffChildren`), similar to a vdom reconciler. https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrdom/src/diff.ts#L104-L121 and https://github.com/rrweb-io/rrweb/blob/rrweb%402.2.2/packages/rrdom/src/diff.ts#L373-L400

## 3. Sentry: the rrweb fork and the replay package

### 3.1 getsentry/rrweb 2.45.0 compared with upstream 2.2.2 (only what was read)
56. Extra record options: `unblockSelector`, `maskAllText`, `unmaskTextClass/Selector`, `maskAttributeFn`, `maxCanvasSize`, `onMutation`, `getCanvasManager`. https://github.com/getsentry/rrweb/blob/2.45.0/packages/rrweb/src/record/index.ts#L91-L134
57. `onMutation(mutations, helpers)` runs before the buffer: returning `false` drops the whole batch and returning an array filters it. Sentry uses it as a kill switch (§3.2 step 64). https://github.com/getsentry/rrweb/blob/2.45.0/packages/rrweb/src/record/observer.ts#L125-L150
58. Canvas is opt-in through injection: with no `getCanvasManager`, a `CanvasManagerNoop` is used, so the canvas code is tree-shaken unless `replayCanvasIntegration` is added. https://github.com/getsentry/rrweb/blob/2.45.0/packages/rrweb/src/record/index.ts#L782-L798. 103. **Worker**: created from an inline Blob. https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/main/app/index.ts#L1118-L1130. The `BatchWriter` splits messages into player, assets, devtools and analytics batches (200 kB soft trigger, 1 MB hard cap). https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/webworker/BatchWriter.ts#L18-L55. `finalize` runs every `flushInterval` (default **30 s**) and on `forceFlushBatch`, `stop` and `closing`. https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/webworker/index.ts#L21 and https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/webworker/index.ts#L101-L118
104. **Upload**: the `QueueSender` POSTs to `/v1/web/i` strictly in order. It gzips with native `CompressionStream` only for batches larger than **24 000 bytes**, and never on unload. Retries: 10 attempts with linear 250 ms backoff. `keepalive` fetch is limited to 64 kB in flight. https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/webworker/QueueSender.ts#L3-L8 , https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/webworker/QueueSender.ts#L55-L58 , https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/webworker/QueueSender.ts#L89-L115

Example tuple (test helper): `[T.CreateElementNode, i, i - 1, i % 5, 'div', false]`. https://github.com/openreplay/openreplay/blob/v1.28.0/tracker/tracker/src/tests/batchWriter_inputDuringStart.test.ts#L79

### 6.2 Highlight (`sdk/highlight-run` 9.16.0 at main 3bf0021)
105. Uses **its own rrweb fork** (`rrweb` workspace package; the repo's `rrweb/` is a submodule to highlight/rrweb). It calls `record()` with `blockClass 'highlight-block'`, `ignoreClass 'highlight-ignore'`, a fork option `privacySetting`, canvas sampling (fps, manual fps, resize factor, max dimension), and the sequential-id plugin. https://github.com/highlight/highlight/blob/3bf002113e555d1ba3d4df648ed44e3503a27e96/sdk/highlight-run/src/client/index.tsx#L1-L6 and https://github.com/highlight/highlight/blob/3bf002113e555d1ba3d4df648ed44e3503a27e96/sdk/highlight-run/src/client/index.tsx#L764-L796
106. Sending: the first push happens after 1 s, then every **2 s** (`SEND_FREQUENCY`); sessions are capped at 4 h. A new full snapshot is taken only when **≥ 10 MB** of events **and** **≥ 4 min** have passed since the last one (canvas: 16 MB and 5 s). https://github.com/highlight/highlight/blob/3bf002113e555d1ba3d4df648ed44e3503a27e96/sdk/highlight-run/src/client/constants/sessions.ts#L1-L36 and https://github.com/highlight/highlight/blob/3bf002113e555d1ba3d4df648ed44e3503a27e96/sdk/highlight-run/src/client/index.tsx#L1455-L1466 , https://github.com/highlight/highlight/blob/3bf002113e555d1ba3d4df648ed44e3503a27e96/sdk/highlight-run/src/client/index.tsx#L1358-L1412
107. In a web worker, the whole payload (events, messages, resources, errors) is `JSON.stringify`'d, compressed with fflate `compressSync` (zlib), base64-encoded, and sent as the GraphQL mutation `PushPayloadCompressed`. https://github.com/highlight/highlight/blob/3bf002113e555d1ba3d4df648ed44e3503a27e96/sdk/highlight-run/src/client/workers/highlight-client-worker.ts#L173-L212

## 7. One-line comparison: Microsoft Clarity (clarity-js v0.8.77)
108. Clarity has its own DOM encoder (not rrweb) and is the only recorder here that *degrades on purpose*: after the same mutation key repeats **10** times (`MutationSuspendThreshold`) outside a **3 s** post-interaction window (`MutationActivePeriod`), it stops sending that mutation and keeps only the latest one until the user interacts. https://github.com/microsoft/clarity/blob/v0.8.77/packages/clarity-js/src/layout/mutation.ts#L220-L250 (constants in https://github.com/microsoft/clarity/blob/v0.8.77/packages/clarity-js/types/layout.d.ts#L156-L159). Upload compression uses native `CompressionStream('gzip')` and is skipped for the last (beacon) payload. https://github.com/microsoft/clarity/blob/v0.8.77/packages/clarity-js/src/data/upload.ts#L183-L204

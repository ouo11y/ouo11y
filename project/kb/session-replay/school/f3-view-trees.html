View trees, platform by platform

Every platform holds a tree of UI objects in memory. How readable that tree is, and how much of the screen it really describes, is different on each one. This is why the same replay idea turns into very different code on iOS, Android, React Native and Flutter.

The pattern: a native view walk reads UIKit and Android Views well, sees SwiftUI and Jetpack Compose as a few opaque drawing views, sees React Native as ordinary native views with RN class names, and sees Flutter as one opaque surface. That is why React Native is recorded by the native SDKs and Flutter is recorded in Dart, as the cross-platform technique lessons show.

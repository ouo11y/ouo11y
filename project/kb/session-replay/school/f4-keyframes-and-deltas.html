Fundamentals

Keyframes and deltas

A recording is a first full picture of the screen followed by small changes. The full picture is a keyframe, the changes are deltas. Every format in this course, from rrweb JSON to H.264 video, is built on this split.

Builds on: Pixels versus structure

One idea, many names

A keyframe (rrweb: full snapshot; video: I-frame; ouo frames: full image) can be shown on its own. A delta (rrweb: incremental snapshot; Datadog: mutation / Change record; video: P-frame; ouo: patches) only means something on top of the frames before it. Deltas are small, but to show second 50 the player must load the last keyframe before 50 and apply every delta after it. If that keyframe is lost or far back, seeking is slow or impossible. A checkout is a keyframe taken on purpose, mid-session, to bound that cost and to let older data be thrown away (Sentry's error buffer keeps only what follows the last checkout).

Seeking: why recorders take checkouts

Move the slider. Every blue mark the player has to apply is work it does before it can show you that second. Then change how often a checkout is taken.

Checkout rules in source: rrweb takes a full snapshot when checkoutEveryNth or checkoutEveryNms is reached, neither set by default (record/index.ts L220–241) · Sentry sets checkoutEveryNms = 60 000 in buffer mode (replay.ts L443–479) · PostHog web takes one every 5 min by timer (L1007–1042) · Datadog web on every RUM view, no timer (startFullSnapshots.ts L12–72) · Datadog iOS on a view id change (SnapshotProcessor.swift L99–127) · Sentry video: an H.264 key frame at most every 6 frames (SentryOnDemandReplay.swift L381–440) and every 5 s segment is its own MP4 · ouo frames: the first frame of every chunk is a full image, chunks cut every 5 s (mobile-replay spec).

Three things follow from the split. Seeking costs "last keyframe + every delta since". Losing a keyframe makes the deltas after it useless until the next one, because deltas name things that only the keyframe introduced (in rrweb, node ids). Buffering is cheap to bound: a recorder that keeps only the last minute in memory can throw away everything before the last checkout.

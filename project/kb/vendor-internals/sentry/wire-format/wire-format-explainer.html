Sentry wire format

Relay 26.10.0 / self-hosted Sentry 26.10.0. Researched 2026-11-10 from Relay source and ~100 requests sent to a local Relay. Details: index.md in this folder.

1. Envelope framing

  • Header lines end with \n (CRLF → 400). Blank lines between items are accepted; a second trailing newline is 400 unexpected end of file.
  • Max 500 items. Only one of event / transaction / security / feedback / replay_event per envelope; else 413 for the whole envelope.
  • Content-Encoding: gzip, deflate (zlib), br, zstd. x-gzip → 415, raw deflate → 400. Limits apply after decompression.
  • Auth: exactly one of X-Sentry-Auth, Authorization: Sentry|Basic, ?sentry_key=, or the envelope dsn. Two at once → 401. sentry_version > 7 → 400.
  • 200 means "queued". Validation, quotas, filters, scrubbing happen after; drops show only as outcomes.

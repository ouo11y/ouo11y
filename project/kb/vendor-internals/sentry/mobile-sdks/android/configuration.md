# Sentry Android SDK: configuration

sentry-java 8.63.0 (tag, 2026-11-05); @sentry/react-native 8.34.0 bundles 8.62.0. Research date 2026-11-10. Method: source read at the tag; docs accessed 2026-11-10.

Every public option of `SentryOptions`, `SentryAndroidOptions`, `SentryReplayOptions`, `SentryFeedbackOptions`, logs/metrics options, and every AndroidManifest meta-data key read by `ManifestMetadataReader`. Defaults are the field initialisers at the tag. "Android:" marks a value that `AndroidOptionsInitializer` or `SentryAndroidOptions` overrides at init. Step 4 summary: [sentry-mobile.md](../../../../client-sdk-features/vendors/sentry-mobile.md). Internals: [architecture.md](architecture.md). Disk and retry: [reliability.md](reliability.md).

Legend: unmarked = read at the linked line. **inferred** / **uncertain** as marked. Callbacks and internal plumbing (`serializer`, `envelopeReader`, `modulesLoader`, `debugMetaLoader`, `threadChecker`, `spanFactory`, `versionDetector`, `socketTagger`, `connectionStatusProvider`, `backpressureMonitor`, `replayController`, `compositePerformanceCollector`, `fullyDisplayedReporter`, `appStartExtender`, `gestureTargetLocators`, `viewHierarchyExporters`) are `@ApiStatus.Internal` or wiring; they are listed only where they change behaviour.

## 1. Where options come from (precedence)

1. `SentryAndroidOptions()` constructor: `attachServerName = false`, SDK name `sentry.java.android` ([SentryAndroidOptions.java#L332-L336](https://github.com/getsentry/sentry-java/blob/8.63.0/sentry-android-core/src/main/java/io/sentry/android/core/SentryAndroidOptions.java#L332-L336)).
2. Android defaults in `loadDefaultAndMetadataOptions` (flush timeout 4000, scope type CURRENT, OTel OFF, cache dir) ([AndroidOptionsInitializer.java#L108-L145](https://github.com/getsentry/sentry-java/blob/8.63.0/sentry-android-core/src/main/java/io/sentry/android/core/AndroidOptionsInitializer.java#L108-L145)).
3. AndroidManifest meta-data (§7) ([ManifestMetadataReader.java#L246-L839](https://github.com/getsentry/sentry-java/blob/8.63.0/sentry-android-core/src/main/java/io/sentry/android/core/ManifestMetadataReader.java#L246-L839)).
4. Release / distinctId defaults if still null ([AndroidOptionsInitializer.java#L520-L548](https://github.com/getsentry/sentry-java/blob/8.63.0/sentry-android-core/src/main/java/io/sentry/android/core/AndroidOptionsInitializer.java#L520-L548)).
5. The `SentryAndroid.init(context, options -> {...})` callback — code wins over manifest ([SentryAndroid.java#L146](https://github.com/getsentry/sentry-java/blob/8.63.0/sentry-android-core/src/main/java/io/sentry/android/core/SentryAndroid.java#L146)).
6. If `enableExternalConfiguration` = true, external options are merged in core `Sentry.init` ([Sentry.java#L613-L616](https://github.com/getsentry/sentry-java/blob/8.63.0/sentry/src/main/java/io/sentry/Sentry.java#L613-L616)). Inferred: this runs after the callback, so external values override code values for the keys they set.

Note: sample rates in the manifest are applied only if the code has not set them yet ("if unset" in §7). Since the manifest is read before the callback, a later code value still overrides.

## 8. External configuration (`sentry.properties`, env, system properties)

## 9. Gradle plugin options that change runtime behaviour

| `includeProguardMapping` / `autoUploadProguardMapping` | true / true | Writes `io.sentry.proguard-uuid` into the manifest (inferred from the meta-data key) |
| `includeSourceContext` | false | Source bundle (bundle ids) |
| `includeDependenciesReport` | true | Module list (`sendModules`) |
| `telemetry` | true | Build telemetry to Sentry (not runtime) |

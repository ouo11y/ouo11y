The app must not pay for the SDK's failures

ouo client SDK golden rule · checklist researched 2026-11-10 · generated from project/kb/client-sdk-safety/

When the SDK fails (a bug, a bad config, a dead network, a full disk, a broken backend, a hostile page, an OS change), the host app keeps working exactly as it would without the SDK: no crash, no hang, no slowdown the user can feel, no changed request, no leaked secret, no lost handler. The SDK loses telemetry before the app loses anything.

P pass, Pa partial, F fail, n/a not applicable, ? not measured. Evidence with file:line is in grades/current-sdks.md.
